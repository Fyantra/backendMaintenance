# backendMaintenance
 Application de gestion pour la maintenance industrielle dans une entreprise textile

Les dependances requis:
* pip install openpyxl (export excel)
* pip install reportlab (export pdf)
* pip install WeasyPrint (rendu html en pdf)
* Télécharge l’installateur de GTK 3 Runtime : https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases
